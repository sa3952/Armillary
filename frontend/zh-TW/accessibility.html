無障礙

無障礙聲明做到哪裡、還沒做到哪裡。

這一頁說明渾儀的網頁對使用鍵盤、螢幕報讀軟體、放大字級或系統對比主題的人，目前做到了什麼、還有哪些已知的缺口。

先說清楚範圍

本站沒有做過第三方無障礙稽核，也不宣稱符合 WCAG 的任何一個等級。下面列的每一項，都是自動測試在真實瀏覽器裡實際檢查的行為；沒有測試在守的，就寫在「還沒做到的」那一節。

自動測試在 Chromium 上跑，每次修改都要通過；Firefox 與 Safari（WebKit）只做不定期的抽查。

目前做到的

  • 鍵盤可以走完整個網站。每一頁開頭有「跳到主要內容」的連結；每一個可以操作的元素（摺疊標題也算）被鍵盤選到時，都有同一種 2px 的外框。
  • 寬表格可以用鍵盤捲動。表格比畫面寬、需要左右捲動時，它的外框才是一個 Tab 停留點，並以表格標題命名；放得下的表格不多佔一站。
  • 計算頁的每一個控制項都有自己的名稱。測試讀的是瀏覽器交給螢幕報讀軟體的無障礙樹：算出結果前後，每一個按鈕、欄位與選項的名稱都不空、也不重複。
  • 錯誤與狀態會被讀出來。送出被擋下時，每一個有問題的欄位帶著自己那一句說明，不是整張表單共用一句；精度、時區等改變會以即時區域朗讀；同一個時刻在當地出現兩次時，焦點會移到選擇區。
  • 中文輸入法不會誤觸搜尋。在地名欄用輸入法選字時按的 Enter 只確認選字，不送出查詢。
  • 字級跟著你的設定。中文字在桌機與手機寬度都至少 12px，並跟著瀏覽器的字級設定放大，不寫死像素。
  • 窄螢幕不需要左右捲動。在 320px 寬（相當於 1280px 寬放大到 400%）時，連同所有選配結果全部展開，頁面本身都不橫向捲動；只有寬表格與章節列在自己的框裡捲動。
  • 減少動態效果。系統設定「減少動態效果」時，每一個動畫與轉場都關掉。
  • 系統的高對比主題。Windows 的對比主題（強制色彩）照系統的顏色顯示；只靠底色表示的「已選」狀態，在這個模式下改用系統的醒目色。
  • 懸停時的文字對比。滑鼠移到按鈕上換底色時，字與底的對比至少 4.5:1，由測試從色彩 token 算出核對。
  • 星盤圖有文字替代。星盤圖與方盤帶有說明上升點的文字標籤；圖上的每一個位置、宮位與相位，在結果頁的表格裡都有同樣的數值。
  • 名詞解釋在手機上是對話框。打開時背後的頁面不能被 Tab 走到，關閉後焦點回到你按的那個按鈕。

還沒做到的

  • 沒有用螢幕報讀軟體逐頁實測。NVDA、JAWS、VoiceOver、TalkBack 都沒有系統性地走過一遍；測試讀的是瀏覽器的無障礙樹，那是報讀軟體拿到的資料，但不等於實際聽到的樣子。
  • 圖的空間關係沒有等價的文字。星盤圖、方盤與文章裡的圖，數值都另有表格或文字，但「哪幾條相位線交錯、哪幾顆星擠在一起」這種一眼看出的關係，沒有逐一寫成文字。
  • 完整結果很長。全部選項都開時，結果頁有上萬個元素；在較慢的裝置上，算完或一次展開全部章節時可能停頓一下。
  • 只有繁體中文，而且術語多。有名詞解釋，但沒有淺白語言的版本，也沒有其他語言。
  • 其他瀏覽器沒有每次都測。Firefox 與 Safari 上的行為只靠抽查；鍵盤在 Safari 預設不會 Tab 到連結與按鈕，需要在系統或瀏覽器設定裡打開。

遇到障礙，請告訴我們

哪一頁、用什麼裝置與輔助工具、卡在哪一步——照〈聯絡方式〉的地址寫信，或在 GitHub issue 回報（issue 是公開的，不要放真實出生資料）。回覆是盡力而為；修好的項目會移到上面「目前做到的」，並加上守住它的測試。
