一般聯絡與錯誤回報

三種用途共用一個地址。這不是把三件事混為一談，是目前只有這一個地址真的收得到信。請不要猜測或改用其他常見信箱別名；未在本頁列出的地址不是可用聯絡管道，信件可能直接被退回。

先講一件跟這個產品其他部分相反的事

寄信給我們，是這裡唯一一個你的資料會被保存下來的地方。

整個服務不保存出生資料。應用程式不把出生資料寫入檔案或資料庫；請求結束後，伺服器記憶體仍可能短暫殘留片段（見〈隱私政策〉）。但一封信就是一封信。依〈隱私政策〉，我們實際保存的只有四樣，其中一樣就是你寄給我們的信（處理完畢後刪除）。

這個地址是 Infomaniak 的 forwarding：依供應商說明，它不建立信箱、不保存訊息，只把信轉到我們的 Proton Mail 信箱。所以我們這一側只有一份，而那一份在 Proton 上以零存取加密保存。

要不要在信裡放真實出生資料，由你決定。下一節把整條路徑攤開讓你自己判斷；我們不會替你決定，也不會因為你不放而少讀一封信。

這封信會走過哪裡

要不要附出生資料，取決於這個。所以講清楚，但不長。

第一站你的郵件商 Gmail、Outlook 或你用的任何一家。它看得到全文。這一段我們改不了。
第二站我們的網域 Infomaniak forwarding。不建立信箱、不保存訊息，只轉送。
終點Proton Mail 信落地的地方，也是唯一持久保存的那一份。
選 Proton 的理由

瑞士：與主機同一個法域，不另外多一個。

零存取加密：信在他們的伺服器上加密保存，Proton 自己讀不到已經存下的內容。

不掃描信件內容投放廣告。

但這些改不了

主旨、寄件位址、時間不加密。那是寫在信封上的字，任何郵件系統都看得到。

加密是「存放時」，不是「全程」。信到 Proton 之前，已經以明文走過前面兩站。

第二站那句「不保存訊息」是供應商的說明，不是我們能驗證的事。

如果你本來就在用 PGP

目前尚未提供OpenPGP Web Key Directory，所以信件不會端對端加密；要不要附出生資料，依上面的說明由你決定。日後若啟用WKD，本頁會列出可核對的本站路徑與使用方式。

如果你沒用過PGP，不需要為了普通聯絡臨時安裝一套不熟的工具。一般問題可以照常使用上列地址，我們會盡力處理。

如果你認為某個數值算錯了

這是最歡迎的一類信。不需要準備什麼，寫信就好。

最少寫這些

哪裡不對：是哪一個數值、你看到什麼、你預期是什麼。

你拿什麼去對：某本書的表、另一個軟體、老師教的算法。對照對象比結論有用得多，我們沒辦法驗證一個沒有對照的直覺。

有的話更好

結果頁的「複製結果」或任何一個下載檔。有它我們通常就能直接重跑同一次計算，省掉好幾封信的往返。

那些內容含有你輸入的出生日期、時間與座標，而且會在好幾個地方重複出現：預設的「運算結果」也有，「運算結果＋驗算資料」更多（輸入收據、時間換算、地點、計算軌跡各有一份）。手動刪幾行刪不乾淨，所以我們不建議這樣做。你可以從下面兩種做法選一種。

寄完整的結果。我們最容易找到問題。信裡會帶著上面這些出生資料，照前面說的路徑傳送，並保存在我們的信箱；寄不寄由你決定，這個取捨也由你自己承擔。我們依〈隱私政策〉處理這封信。

不附出生資料。只截圖出問題的那一區，或改用一組能重現同樣問題的合成資料（計算頁的「載入合成範例」是一個起點）。

要不要附，由你決定。願意讓我們看到出生資料，我們處理得更快；不願意，就只描述現象，我們再一起想辦法。兩種都可以，不必為此猶豫太久。

另外三種信

個資權利請求

查詢或請求閱覽、請求製給複製本、請求補充或更正、請求停止蒐集處理利用、請求刪除。

法定處理期限寫在〈隱私政策〉第一節，主管機關申訴管道寫在第二節，這裡不重複。

要先知道的事：本服務不保存你的命盤。對「刪除我的命盤」這類請求，我們會誠實說明查找結果。沒有可刪除的紀錄，而我們不會虛構一份紀錄來讓流程看起來完整。我們仍會查找你先前的來信，以及供應商層可能持有的連線紀錄。

安全通報

漏洞細節請走 GitHub 的私下漏洞回報，回報內容不會公開。無法使用 GitHub 的話，寄信只說你想回報安全問題、不要附細節，我會另外安排私下管道。完整說明見〈安全〉第 15 節。

界線要說清楚：我們沒有安全港政策，也沒有漏洞獎金計畫。在裁決之前，〈使用條款〉不承諾超出法律範圍的測試授權。

也就是說，歡迎善意通報，但我們現在給不了你一份書面的測試授權。這是資源問題，不是態度問題；有能力做的時候會做。

數字算錯了

寄信或開 GitHub issue 都可以。寫明哪一個數值、你看到什麼、預期什麼，以及你拿來對照的網站或軟體。GitHub issue 任何人都看得到，不要在那裡放真實出生資料：只截圖出問題的那一區，或用計算頁的「載入合成範例」重現；寄信時要不要附，照上面的說明由你決定。

關於回覆速度的實話

本服務規模很小，回覆是盡力而為，不是全天候值班。個資權利請求有法定期限，那是上限，不是我們的目標；多數請求其實不需要查找多久，因為沒有紀錄可以查。

其他信件不設對外時限；我們會盡力閱讀與回覆，但不承諾每封信都能立即處理。

不會發生的事

  • 不會主動寄行銷信。你寄信給我們，不等於訂閱了什麼。
  • 不會把你的信件內容或出生資料交給第三方 AI 處理。
  • 不會用你的來信建立聯絡人資料庫做後續推廣。

這三句是承諾，不是機制。跟本站其他地方不同：那些說「我們做不到」的地方，是因為程式裡真的沒有那個位置；而電子郵件沒有這種結構性保證，能給的只有這三句話和信箱的處置紀律。這個差別我們不打算含糊帶過。
